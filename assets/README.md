# Viltrum logo

Logo design contributed by [@celaldursunduz](https://github.com/celaldursunduz).

| File | Variant | Suggested background |
| --- | --- | --- |
| `logo.svg` | Black mark, transparent background | Light |
| `logo-white.svg` | White mark, transparent background | Dark |
| `logo-black-on-white.svg` | Black mark with white circle | Any |
| `logo-white-on-black.svg` | White mark with black circle | Any |
| `logo.png` | Black mark, transparent background, 512 × 512 | Light |
| `logo-256.png` | Black mark, transparent background, 256 × 256 | Light |

The project README selects the transparent SVG variant for the reader's color
scheme. The PNG files are raster exports of `logo.svg`; use the SVG files when
scalable artwork is supported.
